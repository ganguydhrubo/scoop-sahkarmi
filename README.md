# scoop-sahkarmi

A [Scoop](https://scoop.sh) bucket for [Sahkarmi](https://sahkarmi.site).

Sahkarmi is a desktop app that gives you a small team of AI coworkers running on your
own machine. Each coworker has its own browser and memory. Anything that would leave
your machine, such as a payment, an email or a public post, stops and waits for your
approval first.

## Install

```powershell
scoop bucket add sahkarmi https://github.com/ganguydhrubo/scoop-sahkarmi
scoop install sahkarmi
```

## Update / uninstall

```powershell
scoop update sahkarmi
scoop uninstall sahkarmi
```

## Requirements

Windows 10/11, x64 only. macOS and Linux builds do not exist yet.
